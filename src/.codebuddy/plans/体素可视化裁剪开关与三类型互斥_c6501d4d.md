## 产品概述

优化 CFD 计算结果可视化控件（CDFDxCanvas 的 CFDCanvas 与依赖它的 WindTunnelBox 的 WindTunnelCanvas）的两个行为：远端横截面裁剪的作用范围，以及三种可视化类型的互斥关系。

## 核心功能

1. **裁剪远端横截面新增选项**：新增开关 `ClipSolidModelWithSection`（默认 False）。默认状态下，启用横截面裁剪时只隐藏/裁剪**活动的物理场体素**，`不活动的三维体素模型本体`（CDFDxCanvas 中即 `CfdDataset.Load` 里 `meta.Grid.Mask` 为 0 的体素；WindTunnelCanvas 中即 `btype = CellSolid` 的体素）保持完整显示；仅当该开关为 True 时，模型本体才一并被裁剪隐藏。
2. **三种可视化类型严格互斥**：【体素热图】/【矢量图】/【流线图】在同一时刻只能开启一种，用统一的 `VisualizationMode` 枚举（Heatmap / Vectors / Streamlines）表达，默认 Heatmap。
3. **固体模型本体常驻**：在矢量图模式与流线图模式下，不活动的固体模型本体仍必须完整渲染（不受显示阈值影响），使绕流/轨迹相对模型的空间关系清晰可辨。
4. **速度箭头开关并入矢量图**：移除独立的 ShowArrows 叠加层及其渲染代码，旧的 `ShowArrows` / `ArrowDensity` / `ArrowStride` 属性以弃用包装形式转发到"矢量图"类型与 `VectorStride`，保证既有调用方不中断。
5. **UI 同步**：风洞窗体用"可视化类型"下拉框（热图/矢量图/流线图）取代原来的箭头/矢量/流线三个复选框，并在截面控制行新增"裁剪模型本体"复选框（随截面开关启用）。

## 视觉与交互效果

- 开启裁剪远端后，流体热图按截面被切开，灰色的三维体素模型本体（车体/罐体/挡板等）保持完整轮廓，可清楚看到被剖开区域与模型的相对位置。
- 切换到矢量图：只显示灰色模型本体 + 带 V 形箭头的速度矢量线段；切换到流线图：只显示灰色模型本体 + 流线折线与光点粒子动画；热图点云不再叠加干扰。

## 技术栈

- 语言/框架：Visual Basic .NET，net10.0-windows WinForms 控件库（`Moira.CDFDxCanvas`，RootNamespace `Moira.CDFDxCanvas`）。
- 渲染底层：`Microsoft.VisualBasic.Drawing` 的 `DxScene3DCanvas` / `Direct3D11SceneRenderer`（PointCloud + LineSegment 叠加层，逐点嵌入颜色，`Scene.LoadPointCloud` 会按点集质心重新居中）。
- 既有可复用组件：`Rendering/FlowVectors.vb`（`BuildArrows(IFlowFieldData, VectorArrowOptions)`）、`Rendering/Streamlines.vb`（`StreamlineTracer.Trace` / `StreamlineSet.BuildLines(lut, alpha, ox, oy, oz)` / `StreamlineAnimator`）。
- 受影响工程：`src/CDFDxCanvas`、`src/WindTunnelBox`（ProjectReference 到 CDFDxCanvas）、`src/CFDEngine/test`（DemoTestForm）。

## 实现方案

### 1. 单一事实来源：可视化模式枚举

在 `Rendering` 命名空间新增 `Public Enum VisualizationMode：Heatmap / Vectors / Streamlines`（Heatmap = 0 为默认）。两个画布各自暴露 `Visualization` 属性，内部只维护这一个状态字段；`ShowVectors` / `ShowPathlines` 退化为读写该字段的包装属性，`ShowArrows` / `ArrowDensity` / `ArrowStride` 标记为 `<Obsolete>` 并转发到"矢量图"模式与 `VectorStride`。这样严格互斥由类型系统保证（不可能同时为 True），且不需要散落各处的"互相置 False"逻辑。

### 2. 裁剪开关与固体本体渲染

- WindTunnelCanvas（现象所在）：`RefreshField` Pass 2 的固体分支由
`If Not ShowSolids OrElse Not SliceVisible(i,j,k) Then Continue For`
改为
`If Not ShowSolids Then Continue For` + `If SliceEnabled AndAlso ClipSolidModelWithSection AndAlso Not SliceVisible(i,j,k) Then Continue For`。
- CDFDxCanvas：`CfdDataset.Load` 在构建 `m_active`（mask≠0）的同时构建 `m_solid`（mask=0，即不活动的固体模型本体），新增只读属性 `SolidIndices` / `SolidVoxels`；`VoxelSceneBuilder.Build` 额外生成固体点（统一灰色 `#94A3B8`，value = 0），**不受 Threshold 影响**，仅在 `ClipSolidModelWithSection = True` 时受截面过滤；固体点在 `PointVoxelMap` 中记为 -1，CFDCanvas 的 hover / click / tooltip 三处加 `voxel >= 0` 守卫，避免对固体点做字段拾取。

### 3. 质心补偿（防止模型跳动）

`LoadPointCloud / UpdatePointCloud` 会按点集质心重新居中，因此偏移量必须稳定：

- 基准 `C_ref`：WindTunnelCanvas 沿用 `BindSolver` 中已按"流体 ∪ 固体"统计的 `m_fullCx/Cy/Cz`（无需改动）；CDFDxCanvas 新增 `SceneCentroid`（流体 ∪ 全部固体，懒计算并缓存），保留 `FullCentroid` 不变以免破坏其他语义。
- 当前 `C_vis`：**实际渲染点集**（可见流体 + 已渲染固体）的质心；WindTunnelCanvas Pass 1 需改为同时累加"将被渲染的固体"（现只累加可见流体），否则裁剪时模型会漂移。
- `ox = C_ref.x − C_vis.x`（y/z 同理）；渲染集合为空时保留现有除零/NaN 守卫。

### 4. 模式互斥的渲染分支

- `VoxelSceneBuilder.Build`：`Select Case options.Mode` —— Heatmap 生成流体热图点；Vectors 只调 `BuildVectors`；Streamlines 只调 `BuildPathlines` + `BuildLines`。三种模式都叠加固体本体点。
- WindTunnelCanvas：`If ShowVectors / If ShowPathlines` 改为 `If Visualization = Vectors / Streamlines`；非 Streamlines 分支沿用现有的 `InvalidatePathlines()` + 停表清粒子逻辑。
- 矢量/流线原有的截面与阈值行为保持不变（矢量受截面过滤，流线不裁剪）；色标条保持可见（矢量按速度 LUT 着色）。

### 5. 顺带修正的既有缺陷

`VoxelSceneBuilder.BuildVectors` 生成的线段目前**没有加上 ox/oy/oz 质心补偿**（`lines.AddRange(BuildVectors(...))`），与点云/固体本体不在同一坐标空间。给私有适配器 `DatasetFlowField` 增加 `ox/oy/oz` 构造参数（对齐 `WindTunnelFlowField(nx,ny,nz,u,v,w,btype,ox,oy,oz)` 的既有写法），使 `OriginX/Y/Z` 返回 `Origin + offset`，从根本上消除错位。

## 实现要点（防回归）

- **性能**：固体点数量可能很大。`VoxelViewOptions` 增加 `MaxSolidPoints`（默认 250000），`Build` 内按 `stride ≈ ceil(cbrt(solidCount / MaxSolidPoints))` 对固体做确定性抽稀（与 WindTunnelCanvas 用 `MaxPoints` 求 `m_stride` 的既有做法一致），内存与每帧传输量可控；`ShowSolids = True` 默认开启，用户可整体关闭。
- **热路径取舍**：Pass 1 与抽稀同循环完成，不新增整场扫描；`SceneCentroid` 与 `SolidIndices` 均一次构建/懒计算缓存，不进入逐帧路径。
- **兼容性**：`ShowArrows` 等旧属性保留为 `<Obsolete>` 包装（DemoTestForm 仍在调用），避免大范围破坏；不再维护旧的简单箭头渲染路径（`VoxelSceneBuilder.BuildArrows`、`WindTunnelCanvas` 569–618 行、FormWindTunnel 的 `m_chkArrows`）以免保留两套互斥不一致的开关。
- **日志/异常**：沿用现有风格——流线追踪失败静默降级（`Try/Catch → m_streamSet = Nothing`），不新增日志输出，不向 UI 抛异常。

## 架构设计

```mermaid
flowchart TD
    A[CFDCanvas / WindTunnelCanvas] -->|Visualization: Heatmap|Vectors|Streamlines| B[VoxelViewOptions.Mode]
    A -->|ShowSolids / ClipSolidModelWithSection| B
    B --> C[VoxelSceneBuilder.Build]
    C --> D[活动流体热图点 LUT 着色 + 阈值]
    C --> E[固体本体点 #94A3B8 常驻]
    C --> F[FlowVectors.BuildArrows 矢量线段]
    C --> G[StreamlineSet.BuildLines 流线 + 粒子]
    D --> H[质心补偿 ox/oy/oz = C_ref - C_vis]
    E --> H
    F --> H
    G --> H
    H --> I[DxScene3DCanvas 场景]
```

状态单一化：画布层只有一个 `Visualization` 字段 + 两个布尔开关（`ShowSolids`、`ClipSolidModelWithSection`）；渲染层只依据 `VoxelViewOptions` 快照工作，无跨帧隐藏状态。
