按照**求解链条的五个核心模块**（FVM 骨架 → 旋转处理 → 欧拉两相流 → 湍流 → 压力-速度耦合）逐层拆解，每个模块讲清数学方程、离散方法、实现要点，最后给出针对引擎开发的优化路线。

## 〇、整体求解框架：先建立全局图景
一条完整的发酵罐通气搅拌求解链是这样的：
```
几何与网格(滑移区 + 静止区 + interface)
      ↓
控制方程组(每相的连续/动量 + 湍流 + 气泡尺寸 + 氧传质)
      ↓
FVM 离散(通量格式 + 源项线性化)
      ↓
旋转处理(MRF: 参考系变换附加源项 / 滑移网格: interface 动态插值)
      ↓
压力-速度-体积分数耦合(SIMPLE 族多相扩展)
      ↓
时间推进(稳态 MRF 或 非稳态滑移)
      ↓
目标量提取(Np 功率准数、气含率、kLa、混合时间)
```
**核心耦合逻辑**：桨叶旋转提供能量输入 → 决定湍流场 → 湍流耗散率 ε 决定气泡破碎/聚并与传质系数 kL → kLa 与液相氧浓度输运耦合 → 反馈到流场密度/粘度（若考虑发酵液流变演化）。

## 一、FVM 有限体积法：整个引擎的骨架
### 1.1 出发点：守恒律的积分形式
FVM 不对微分方程直接差分，而是对**任意控制体上的积分守恒律**离散，这保证离散层面守恒（质量/动量不会因离散误差凭空产生或消失）——这是它相对 FDM 的本质优势。
对任意守恒量 φ：
```
d/dt ∫_V ρφ dV + ∮_S ρφ(v·n) dS = ∮_S Γ∇φ·n dS + ∫_V S_φ dV
    [时间累积]      [对流通量]          [扩散通量]        [源项]
```
对网格单元 P，记 f 为其面，可得半离散形式：
```
d(ρ_P φ_P V_P)/dt + Σ_f [ρ_f φ_f (v_f·S_f)] = Σ_f [Γ_f (∇φ)_f · S_f] + S_φ V_P
```
### 1.2 每个面的三个关键量（引擎的核心数据结构）
实现时每个面需要存储/计算：
| 量 | 物理含义 | 典型实现 |
|---|---|---|
| `v_f·S_f` | 面法向质量通量 | 由压力修正方程更新 |
| `φ_f` | 面上的对流量取值 | 由对流格式决定（**精度核心**） |
| `(∇φ)_f` | 面梯度 | 节点梯度插值或面法向导数 |
**对流格式是精度与稳定性的权衡点**，你的引擎至少要实现：
- **一阶迎风**：φ_f = φ_upwind。绝对稳定、有界，但数值扩散严重——对发酵罐这种强旋流会把桨叶尾涡抹平，**只用于启动收敛或欠松弛初场**；
- **二阶迎风（linear-upwind）**：φ_f = φ_up + ∇φ·d。精度二阶，高梯度区易振荡；
- **中心差分**：二阶，无数值扩散，但对流占优时不稳定，需与迎风混合（如 0.9 中心 + 0.1 迎风）；
- **QUICK / TVD / MUSCL**：三阶有界格式，桨叶通道流这类强梯度场景推荐 TVD 类（如 van Leer 限制器），兼顾精度与不产生新的极值。
**扩散项**：面梯度计算需要节点梯度，标准做法是 **Gauss-Green 散度定理**（对单元用其所有面上的面值平均）或**最小二乘梯度**（对非正交网格更稳健，OpenFOAM 的 `lsGrad`）。非正交修正：`面法向导数 = 显式修正 + 隐式正交部分`，正交性差的网格（滑移 interface 附近常见！）必须做，否则精度掉一阶。
**梯度限制器**（Barth-Jesperson / Venkat）对 kLa、气含率这类必须物理有界（0≤α≤1）的量是刚需，防止出现负体积分数导致发散。

## 二、旋转处理：MRF 与滑移网格的原理与差异
这是发酵罐引擎区别于通用 CFD 代码的**第一特色模块**。
### 2.1 MRF（多重参考系）：参考系变换，网格静止
**原理**：将桨叶周围一圈区域（圆柱体）内的方程改写在**旋转坐标系**中求解，网格完全不动。旋转系下动量方程多出两个附加源项：
```
ρ(∂v_rel/∂t) + χ·(ρ v_rel v_rel) = -∇p + ρ∇·τ + ρg 
    + **[-2ρΩ×v_rel]**        ← 科氏力
    + **[-ρΩ×(Ω×r)]**         ← 离心力
    + **[-ρ dΩ/dt × r]**       ← 欧拉力(Ω恒定时为零)
```
**Interface 处理**：旋转区与静止区交界面上做速度变换：
```
静止区观察的绝对速度:  v_abs = v_rel + Ω×r
```
即通量穿越 interface 时，把旋转区算出的相对速度加上牵连速度传给静止区。这一步实现简单——只是面上的向量加法。
**MRF 的本质近似**：求解的是**稳态化**的流场，相当于桨叶“冻结”在某个相位角上，旋转区与静止区之间通过局部绝对速度连续传递信息。代价：
- 无法捕捉桨叶扫过挡板的**周期性相互作用**（挡板诱发的尾涡脱落、周期性压力脉动全部丢失）；
- interface 上速度分布是相位平均意义下的近似，会人工生成虚假湍流；
- **interface 半径与高度的选取是人为超参数**——同一工况不同 MRF 区域划分，预测的混合时间可以差 3 倍（我们前面对话已确认），这是 MRF 最大的系统性误差来源。
**实现优先级**：MRF 是你引擎的第一块积木，实现成本最低（一个源项 + interface 速度变换），用于快速迭代和稳态收敛。
### 2.2 滑移网格：真正捕捉瞬态旋转
**原理**：旋转区网格整体**刚体转动**，每步推进后旋转区与静止区在 interface 上相对滑动，两套不匹配的网格之间传递通量。
**核心算法：通用网格交界面**：
```
第 n 步: 旋转区转角 θ_n，与静止区在interface重叠
第 n+1 步: 旋转区转角 θ_n + ωΔt，界面两侧面发生错位
```
每个时间步必须重建 interface 的**插值权重**：
1. 求滑移区面 i 与静止区面 j 的**几何重叠**（3D 多边形求交，clip 算法）；
2. 生成重叠权重 G_ij = |S_i ∩ S_j|；
3. 面通量守恒传递：静止区面 j 从旋转区面 i 获得的通量 = Σ_i G_ij/S_j × (旋转区面 i 上的通量)；
4. 保证**总体守恒**：权重矩阵按行/列归一化（两侧通量代数和相等，否则质量泄漏）。
**实现难点与性能陷阱**：
- 每步的多边形求交是 O(N_f × M_f) 暴力算法的话会拖垮性能——必须用**旋转角度哈希/环形分区**（interface 是环形，两侧面按角度排序后局部搜索，退化为近线性）；
- 插值是双线性而非物理格式，穿过 interface 的对流格式退化为一阶，因此 **interface 布置在梯度平缓区**（远离桨叶和挡板）至关重要；
- interface 两侧网格间距尽量接近（1:1 到 2:1），错位带来的插值误差与面积失配成正比。
**滑移网格能捕捉的**：桨叶-挡板的周期性干涉、气穴（cavity）随桨叶相位的变化、尾涡结构、真实的启动瞬态——这些直接影响 kLa 的预测精度。
### 2.3 混合策略（工程常用）
先用 **MRF 跑到收敛拿到稳态初场**，再切换滑移网格做非稳态若干个桨叶周期（10–20 个周期达到统计稳态），在统计窗口上平均得到目标量。这一策略能省一半以上计算量，建议在你的引擎里设计为标准工作流。

## 三、欧拉-欧拉两相流模型：双流体框架
### 3.1 控制方程组
设液相 l（连续相）、气相 g（分散相），体积分数 α_l + α_g = 1，**两相共享同一个压力场** p（工程近似，对搅拌罐低压差场景足够）：
**q 相连续性方程**：
```
∂(α_q ρ_q)/∂t + ∇·(α_q ρ_q v_q) = 0
```
**q 相动量方程**（这是发动机最复杂的方程）：
```
∂(α_q ρ_q v_q)/∂t + ∇·(α_q ρ_q v_q v_q) 
  = -α_q ∇p                          ← 压力(共享)
  + ∇·(α_q τ_q_eff)                  ← 粘性+湍流应力
  + α_q ρ_q g                        ← 重力(气泡升浮的关键)
  + M_q → 相间动量交换项              ← 体积力形式的相间力
```
注意两项相的动量方程中相间作用力 **M_ql = -M_lg**（牛顿第三定律），只需建立一次曳力等模型。
### 3.2 相间作用力模型（按重要性排序）
| 力 | 模型 | 对发酵罐的意义 |
|---|---|---|
| **曳力** | Schiller-Naumann、Ishii-Zuber、Grace、Tomiyama | **主导项**，决定气含率与气泡停留时间，决定 kL 的速度差 |
| 升力 | Tomiyama（含 Eötvös 数变号） | 气泡在尾涡区聚集或弹出的关键 |
| 虚拟质量力 | C_VM ≈ 0.5 | 桨叶强加速区重要，增强耦合刚性 |
| 湍流分散力 | Lopez de Bertodano / Burns FTD | 把气泡从高气含区向低区扩散，防数值聚集 |
**曳力实现细节**：曳力以 F = (3/4)·C_D·(α_g ρ_l / d_b)·|v_l - v_g|·(v_l - v_g) 的形式加入动量源项，隐式化处理相对速度法向分量保证稳定。C_D 是 Re_g 和 α_g 的函数——**这里就埋下了与气泡尺寸的耦合点**。
### 3.3 气泡尺寸：群体平衡模型（PBM）
发酵罐的 kL 与 d_b 强相关（kL∝d_b^{-m}），而 d_b 由破碎/聚并平衡决定，**不做 PBM 就只能输入常数 d_b，误差可达数倍**。
数密度输运方程：
```
∂n(v,t)/∂t + ∇·(n v_g) = B_B(v) - D_B(v) + B_C(v) - D_C(v)
                          [破碎生成-死亡 + 聚并生成-死亡]
```
**求解方法三选一**（你的引擎按难度递进实现）：
1. **离散分组法**：把气泡尺寸分成 N 个 bin（如 0.5–10 mm 分 12–20 组），每个 bin 解一个标量输运方程，破碎/聚并率通过 bin 间转移矩阵表达。实现直接、精度可控，是工业主流，代价是标量方程数量 ×N；
2. **矩方法（SMM/MUSIG 平衡版）**：输运 3–5 个矩（m_k = ∫v^k n dv），用预设尺寸分布闭包。计算省，但无法描述双峰分布；
3. **QMOM 正交矩**：高精度但闭包复杂，学术改进方向。
**破碎核**（Luo-Svendsen：基于湍流涡碰撞能量与表面张力之比）与**聚并核**（Luo / Prince-Blanch：气泡碰撞频率 × 聚并概率）都强依赖 **湍流耗散率 ε**——这是“湍流模型 → PBM → kLa”耦合链的数学实现点。
### 3.4 氧传质与反应
**kL 模型**（Higbie 渗透理论类）：
```
kL = C · D_O2^{1/2} · (ε/d_b)^{1/4}     (Lamont-Scott 类)
Sh = 2 + 0.015·Re^{0.86}·Sc^{0.33}       (Kawase-Moo-Young 类)
```
液相氧输运方程（标准标量方程 + 源项）：
```
∂(α_l C_O2)/∂t + ∇·(α_l v_l C_O2) = ∇·(α_l D_eff ∇C_O2) + **kLa(C*_O2 - C_O2)** - **R_代谢**
```
C* 由亨利定律从气相氧分压给出。R_代谢 若做长时演化耦合可加 Monod 动力学，并可反耦合流变（菌体生长→粘度变化→重新标定 MRF 等效流场）。

## 四、湍流模型：发酵罐场景的选择与多相扩展
### 4.1 RANS 模型选择
搅拌罐高应变率、强旋转、曲率显著的流动，**标准 k-ε 会失效**：
- **Realizable k-ε**（推荐默认）：修正了 ε 方程的生成项保证可实现性，对圆腔流/强曲率稳健，Fluent 搅拌验证库的默认选项；
- **RNG k-ε + 旋流修正**：ε 方程附加 -ρ(η³(1-η/η₀)/(1+β η³)) 项，对旋转流动有修正，也是常用选择；
- **RSM 雷诺应力模型**：各向异性显式求解，对尾涡各向异性描述更好，收敛更难、成本 ×2，作为高精度选项。
### 4.2 多相湍流的两种处理（引擎需实现开关）
1. **混合湍流模型**：解一套 k-ε（混合速度、混合粘度），成本低，适用 α_g 较低；
2. **逐相湍流模型**：每相各自的 k-ε（或气相用代数模型），高气含率（>15%）更准，收敛更刚性。
**气泡诱导湍流**：Sato 模型，μ_t,g = C μ_t,l ρ_l/ρ_g + 气泡尾迹项——通气量大的罐不可忽略，否则桨叶区湍流被低估 → ε 低估 → 破碎率低估 → d_b 偏大 → kLa 偏低，形成系统性误差链。
### 4.3 近壁处理
用**壁面函数**（标准/非平衡 Scalable）即可，y+ 控制在 30–300；桨叶和挡板是主要剪切源，不必上低雷诺积分到壁。注意 MRF 区内的壁面速度需按相对速度处理。

## 五、压力-速度-体积分数耦合：SIMPLE 族的多相扩展
这是引擎最核心的数值层。
### 5.1 分离式求解流程（单个时间步内的内迭代）
```
1. 初始化 α, p, k, ε, v_l, v_g
2. 循环内迭代:
   a. 用当前 p 解液相动量方程 → v_l*
   b. 解气相动量方程 → v_g*
   c. [MRF: 旋转区附加源项已并入 / 滑移: 重建interface权重]
   d. 相耦合压力修正方程 (PCSIMPLE):
      ∇·(α_l ρ_l v_l' + α_g ρ_g v_g') = -残余质量源
      其中 v' 来自动量方程的隐式压力系数 d_f = A_f/a_P
   e. 解出 p' → 修正 p, v_l, v_g
   f. 解 α_g 输运方程(有界格式+限制器)
   g. 解 k, ε, PBM bin方程, C_O2
   h. 更新物性(流变、气泡相关量), 检查残差
3. 残差达标 → 推进到下一时间步
```
**多相压力修正的特殊性**：修正方程的系数是两相系数之和 `α_l ρ_l d_l + α_g ρ_g d_g`，且连续性方程是两相体积通量之和为零——这一项实现时容易遗漏相位乘子导致质量不守恒。
### 5.2 数值刚性来源与对策（发酵罐特有）
- **密度比 1000:1**：气相动量方程系数很小，收敛慢。对策：气相用更大的欠松弛（0.5–0.7），液相谨慎（0.3–0.5）；
- **曳力强耦合**：气液速度差大时相间力项刚性。对策：曳力隐式化（把 (v_g - v_l) 中一相速度放在隐式侧）；
- **压力-气泡浮力耦合**：气相上浮会形成通道流。对策：时间步长与 α 输运的 Courant 数联合限制，滑移网格典型 Δt = 桨叶转过 1–3° 对应的时间（如 100 RPM → Δt ≈ 1.7–5 ms）。
### 5.3 时间推进格式
- **一阶隐式**：稳定但耗散大，只用于初场建立；
- **二阶隐式（BDF2/Crank-Nicolson 带混合因子）**：非稳态滑移计算必须二阶，否则桨叶周期性压力脉动幅值被抹平，直接影响砰击/功率脉动预测；
- 时间步内的内迭代（PISO 风格的多次压力修正）比一次性修正更稳健。

## 六、针对引擎开发的优化与改进路线
基于以上原理，给你一个**从正确性到效率**的进阶清单：
### 6.1 正确性层（先做对）
1. **守恒审计**：滑移 interface 每步打印两侧通量差（应 <10⁻⁶ 量级），MRF interface 检查绝对速度连续性——这两个是新手引擎最隐蔽的 bug 源；
2. **有界性保证**：α 方程强制 TVD + 限制器，任何一步出现 α<0 或 >1 都应触发截断回退而非静默 clamp（clamp 会破坏守恒）；
3. **基准验证矩阵**：Rushton 桨无通气（对比 Np ≈ 5–6 文献值）、Rushton + 通气（气含率-转速关系）、kL 实验关联式（如 Smith 等经典数据）。**没有这个矩阵，后续任何优化都无法评估好坏**。
### 6.2 物理模型层（改进方向）
1. **MRF 区域敏感性研究**：你的引擎可以做一个原创贡献——系统量化 interface 半径/高度对混合时间、气含率的影响，提出自适应 MRF 区域选取准则（现有文献显示误差可达 3 倍，但选区准则缺乏系统研究）；
2. **非牛顿流变耦合**：丝状菌发酵液的幂律/Cross 粘度，注意粘度依赖剪切率 → 迭代求解有效粘度（每个内迭代用当前 |∇v| 更新），这是 SPH 对话里提过的真实痛点，FVM 侧同样要做对；
3. **PBM 核函数改进**：Luo-Svendsen 破碎核在低 ε 区预测偏高，可基于实验数据重整参数；
4. **kL 闭包标定**：内置 2–3 个 kL 模型供切换，暴露为可配置参数。
### 6.3 数值层（效率优化）
1. **滑移 interface 加速**：如前述环形角度哈希把通量重建从 O(N²) 降到近 O(N)，这是你引擎相对通用代码（如某些开源实现）可以做得更好的点；
2. **代数求解器选择**：压力修正方程是大型稀疏对称正定系统 → **代数多重网格（AMG）** 是标配，CG+Gauss-Seidel 光滑；标量方程用 BiCGStab+ILU。没有 AMG，网格上百万单元后每步耗时会不可接受；
3. **GPU 化路线**：压力求解（AMG 的聚合层）与显式通量计算是最适 GPU 的模块；动量方程装配因非牛顿/相间力的不规则访问，需要 coloring 重排后并行；
4. **自适应时间步**：以滑移区转过角度与 α Courant 数双准则动态调 Δt，可省 30–50% 步数。
### 6.4 架构层（为长期演进留接口）
- 把“物理模型（曳力/破碎核/kL）”、“离散格式”、“耦合算法”设计成可插拔模块——你后续想换 LES 湍流或 EE-DEM 耦合时不需要重写求解器主循环；
- 预留 MRF ↔ 滑移网格切换的元数据（interface 定义、区域标记），实现“MRF 收敛 → 滑移启动”的一键工作流；
- 数据结构上，非结构化多面体网格（OpenFOAM 风格的 owner/neighbour 面表）比结构化分块更适合未来混合滑移/自适应。

## 七、推荐学习与参考实现
- **OpenFOAM**：`rotorDiskMRF`、`AMI（arbitrary mesh interface）`、`reactingMultiphaseEulerFoam`（含 PBM + 传质的多相框架）——代码全开源，是构建引擎最直接的参考，滑移网格（AMI）的守恒插值实现就在 `meshToMesh`/`AMIInterpolation` 类里；
- **Fluent 理论文档**（Theory Guide 的 Multiple Reference Frames、Eulerian Multiphase、Population Balance 章节）：模型公式最完整，交叉验证你的实现；
- 经典论文：Brucato 等（搅拌罐湍流量化）、Luo & Svendsen 1996（破碎核）、Montante 等（通气 Rushton 的 CFD-实验对比）。

**一句话路线图**：先用 MRF + Realizable k-ε + 双流体（常数 d_b）把骨架跑通并验证 Np；再加 PBM 离散分组法与 kL 闭包打通传质链；最后上滑移网格（AMI）做非稳态，捕捉桨叶-挡板干涉与 kLa 的相位相关性。物理建模的每一步改进都建立在守恒性与有界性的数值地基之上——这个顺序不要颠倒。
